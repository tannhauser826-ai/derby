# IA (MVP, 로그인 제외)

## 1) 홈 `/`
- 오늘의 추천 레이스 TOP N
- 모드 필터: beginner/date/family/photo/indoor
- 추천 사유 1~2줄

## 2) 레이스 목록 `/races?date=YYYY-MM-DD`
- 날짜 선택
- 레이스 카드: 시간/거리/등급/추천 배지

## 3) 레이스 상세 `/races/[raceId]`
- 관전 포인트
- 추천 사유
- 주요 출주 엔티티(말/기수/조교사)
- 관련 스토리
- 좌석 가이드 바로가기 CTA

## 4) 스토리 피드 `/stories`
- 타입 필터: horse/jockey/trainer/race
- 태그 필터 + 키워드 검색
- 카드형 리스트

## 5) 트랙·좌석 가이드 `/guides/seats?mode=`
- 유형 선택
- 추천 구역/이유
- 주의사항(그늘/실내/푸드존 동선)

## 6) 이벤트 `/events?date=`
- 날짜별 행사/푸드/즐길거리

## 사용자 흐름 (핵심)
1. 홈에서 모드 선택
2. 추천 레이스 상세 확인
3. 스토리로 흥미 유도
4. 좌석 가이드로 현장 동선 확정
